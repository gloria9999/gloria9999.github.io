도메인 모니터링 자동화

운영자가 지정한 도메인 목록을 Google Sheets의 대장·예외 목록과 비교하고, 웹사이트의 HTTP 응답과 페이지 제목을 확인하는 개인 업무용 도구입니다. 현재 클라우드 자동 실행을 준비하고 있습니다.

개인정보처리방침 · 이용약관 · 문의

주요 기능과 Google 데이터 이용 목적

  • 지정된 Google Drive 입력 폴더에서 CSV 파일 읽기
  • Google Sheets의 대장·예외·우선페이지 목록과 비교
  • 공개 웹사이트의 HTTP 응답, 이동 경로, 제목 확인
  • 지정된 Drive 결과 폴더에 CSV·Excel 결과 저장
  • 지정된 Google Sheets에 점검 결과와 처리로그 기록

Google 계정 연결은 사용자의 OAuth 동의를 통해 이루어집니다. 현재 연결 테스트는 읽기 전용이며, 결과 저장 기능에는 별도의 쓰기 권한 동의가 필요합니다.

개인정보처리방침

이 도구는 사용자가 승인한 Google Drive 파일과 Google Sheets의 도메인 목록, 비교 기준 및 점검 결과를 업무 처리 목적으로 이용합니다. Google 계정 비밀번호를 수집하지 않습니다.

처리 과정에서 파일 식별자, 파일명, 도메인, 웹페이지 제목, HTTP 응답 및 점검 시각이 사용될 수 있습니다. OAuth 인증 정보는 Google API 접근을 위한 인증에만 사용합니다.

결과와 처리 이력은 운영자가 지정한 Google Drive·Google Sheets에 보관하며, 로컬 실행 시에는 운영자의 컴퓨터에도 저장됩니다. GitHub Actions 실행을 구성하는 경우 실행 중 필요한 자료를 GitHub의 실행 환경에서 처리하고 인증 정보는 GitHub Secrets로 관리합니다. 이 공개 안내 사이트에는 업무 자료나 인증 정보를 게시하지 않습니다.

Google 사용자 데이터를 판매하거나 광고 및 범용 AI 모델 학습에 사용하지 않습니다. 기능 제공에 필요한 Google 및 실행 인프라를 통한 처리를 제외하고 외부에 제공하지 않습니다.

저장된 결과와 이력은 운영자가 업무상 필요한 기간 보관하고 필요하지 않으면 삭제합니다. 사용자는 Google 계정의 연결된 앱 관리에서 접근 권한을 철회할 수 있습니다. 권한 철회만으로 기존 결과 파일이 자동 삭제되지는 않습니다. 저장 자료 및 인증 정보의 삭제는 아래 연락처로 요청할 수 있습니다.

Google API에서 받은 정보의 사용 및 다른 앱으로의 전송에는 Limited Use 요구사항을 포함한 Google API Services User Data Policy 를 준수합니다.

이용약관

이 도구는 운영자와 운영자가 허용한 사용자의 업무용으로 사용합니다. 사용자는 접근 권한이 있는 파일과 시트만 연결해야 합니다.

점검 결과는 점검 시점의 관측 정보입니다. 네트워크 상태나 사이트 변경에 따라 달라질 수 있으며, HTTP 응답만으로 사이트의 등록 여부나 위법성을 판단하지 않습니다. 중요한 판단 전에는 사용자가 결과를 확인해야 합니다.

외부 서비스의 장애·사용량 제한 등에 따라 실행이 지연되거나 중단될 수 있습니다. 사용자는 계정 연결을 해제하여 이용을 중단할 수 있습니다.
